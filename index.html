    Using this page

    Open this HTML file in a full browser. Everything needed for MP3 export, video snapshots, recording dates, and speech-pause analysis is built into this file. Only Gemini transcription needs internet access. Your clips stay in this tab until you close or reload it.

    1. In Voice Memos, select your recordings, tap Share, then Save to Files.
    2. Open this page in Safari, tap Add audio or video, and select your exported recordings.
    3. Check the numbered order, then tap Join & export MP3. Save the finished file using the buttons above.

    Uploads are sorted by their embedded recording time, including the time of day. If it is missing, the file’s modification time is used and labeled File time. Files with no usable date keep their upload order at the end. Editing or exporting a file can change its date. New uploads sort the queue again; use the arrows afterward for a manual adjustment.

    Common audio formats include MP3, M4A, AAC, WAV, AIFF, FLAC, OGG, Opus, WMA, and CAF. You can also add MOV, MP4, MKV, WebM, AVI, and other common videos. The first audio track from each video is used; videos without audio cannot be exported.

    The media decoder is included in this HTML file. Reading recording dates and converting supported formats work offline, including the first time you open it. MP3 conversion is processed on this device. Protected files and some codecs cannot be converted. Large files need more memory. Keep this page open; reloading clears your clips.

    Transcription uses Gemini 3.5 Transcribe. When you add a recording, a background worker measures volume and checks speech activity near each 15-minute mark. Expand the section list under a clip to see its cut times. It searches for a pause within 30 seconds of each mark, extending to 60 seconds if needed. Cuts preserve the entire recording, including silence. If no clear nearby pause is found, that cut uses the 15-minute mark and is labeled in the list. Speech detection estimates speech activity; it does not identify exact words. Each section is encoded locally as a compact MP3 before being sent. The next section waits for the previous response and the pause set at the top, which defaults to five seconds. Completed text appears in recording order. Gemini’s timestamps are relative to each section; this page adds that section’s exact cut time after the response returns. Timestamps restart only when a different original source file begins, and source filenames separate multiple files. Speaker labels are omitted. Copy text, Share / Messages, and Download TXT use the text shown, with a blank line between clips. On iOS, Share / Messages opens the share sheet when supported; choose Messages there. Preview playback depends on your browser. A clip that cannot preview may still export.

    Videos also produce snapshots at 0:00 and every five minutes before the video ends. Each frame retains its decoded resolution and is saved as a lossless PNG. A black footer is added below the frame with the actual frame time and complete source filename. A standard 1920 × 1080 frame becomes 1920 × 1100; long captions can extend the footer further to fit. Download the images individually or together in their own ZIP. Available source metadata is embedded in each PNG and included as metadata.json in the ZIP. Video frames stay on this device and are not sent to Gemini. A video without audio can still produce snapshots.

    Clips are placed directly back to back. Any silence already in a recording stays in it.
